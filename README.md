# QuickBrowse

Небольшой браузер для Windows на движке Microsoft Edge WebView2 (Chromium),
с тёмной боковой панелью, стартовой страницей с поиском и быстрым доступом
к популярным сайтам.

## Возможности

- Вкладки: кнопка «+», закрытие кнопкой «×» или средней кнопкой мыши.
- Адресная строка: открывает адрес сайта или ищет запрос в Google.
- Переход назад/вперёд, обновление страницы и домашняя страница.
- Закладки и история с сохранением между запусками.
- Загрузка файлов в папку `Загрузки` профиля Windows.
- Ссылки, открываемые сайтом в новом окне, открываются в новой вкладке.
- Горячие клавиши: `Ctrl+T` — новая вкладка, `Ctrl+W` — закрыть вкладку,
  `Ctrl+L` — перейти к адресной строке.

Это браузерное приложение на движке Edge, а не отдельная реализация Chromium.

## Сборка и запуск

Нужны Windows 10/11, .NET 8 SDK и Microsoft Edge WebView2 Runtime. Runtime
обычно уже установлен вместе с Microsoft Edge.

Из PowerShell в папке `QuickBrowse` выполните:

```powershell
dotnet restore
dotnet run
```

Чтобы собрать приложение:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true
```

Параметр `--self-contained true` включает .NET в публикацию: на компьютере,
где запускается собранный браузер, .NET Runtime устанавливать не нужно.
Microsoft Edge WebView2 Runtime всё равно необходим для отображения сайтов.

## Создание установщика Windows

Для создания установочного файла нужны .NET 8 SDK и Inno Setup 6. Перед сборкой
закройте QuickBrowse, чтобы Windows не блокировала обновление его файлов.

Запустите `build-installer.ps1` из папки проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\build-installer.ps1
```

Готовый установщик появится в `installer\QuickBrowse-Setup-1.0.0.exe`.
Он устанавливает браузер в папку пользователя, создаёт пункт в меню «Пуск»
и предлагает добавить ярлык на рабочий стол.

Данные браузера хранятся в `%APPDATA%\QuickBrowse`; файлы загружаются в
`%USERPROFILE%\Downloads`.
